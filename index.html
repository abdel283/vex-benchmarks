Vex vs CanvasMC

Tick time, lag spikes and CPU use, measured on the same PC with the same world, the same players and the same Java settings. Lower is better everywhere on this page.

How to read this

MSPT (milliseconds per tick) is how long the server needs for one game tick. Minecraft runs 20 ticks per second, so every tick has a 50 ms budget. The less of it a tick uses, the more players, farms and plugins the server can take before it starts to lag.
