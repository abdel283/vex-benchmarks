# Vex vs CanvasMC benchmarks

Live page: https://abdel283.github.io/vex-benchmarks/

Tick time (MSPT), lag spikes (99th percentile MSPT), TPS and CPU use of Vex and CanvasMC on Minecraft 26.2, measured on
the same PC with the same world, bots and Java settings. Every test ran twice per server with the servers taking turns.

- `index.html`: the page (no external scripts, fonts or trackers)
- `data.json`: every number on the page, per run
