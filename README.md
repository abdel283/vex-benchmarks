# Vex vs CanvasMC vs Folia benchmarks

Live page: https://abdel283.github.io/vex-benchmarks/

Tick time (MSPT), lag spikes (99th percentile MSPT), TPS, CPU and memory use of Vex and CanvasMC on Minecraft 26.2 and
Folia on Minecraft 26.1.2, measured on the same PC with the same world settings, bots and Java settings. Every test ran
twice per server with the servers taking turns; runs that lost bots during the measurement are not counted.

- `index.html`: the page (no external scripts, fonts or trackers)
- `data.json`: every number on the page, per run
